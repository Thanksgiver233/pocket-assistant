# pocket-assistant
「随身」是一个运行在你自己机器上的个人助理。它不追求"更强的模型"，而是回答一个更难的问题：凭什么把权限交给一个 AI？ 它的每一个动作都先经过十三层裁决——高风险先停下来问你，做完给你一张可撤销的小票：读了什么数据、用了哪个连接器、花了多少钱、怎么撤销，一目了然。主动推送受"打扰预算"约束，每日配额用完即静默，绝不因为"重要"而破例。记忆分层存储，可查看、可删除、可一键导出带走——你的数据是你的，不是训练语料，也不是锁定手段。 功能上覆盖三条主线：自然语言改日程与智能提醒、随手记与自动成稿的工作日记、有节制的灵感建议。内核是零依赖的 Node 模块，Web、Windows、Android 三端同构；单用户一年总成本约 263 元，跑在一台 68 元的轻量服务器上。
